# Shivam Kumar — Full-Stack Developer Portfolio

A modern, interactive personal portfolio built with **HTML5, CSS3, and Vanilla JavaScript**.

The portfolio is intentionally grounded in the actual projects and technology stacks represented by my GitHub repositories. It does not display fabricated repository stars, forks, contribution totals, portfolio balances, GPA values, or simulated market data.

## Portfolio Features

- Responsive layout for desktop and mobile
- Multi-theme interface
- Canvas particle background
- Smooth scrolling and section navigation
- Project filtering
- Project detail modal backed by verified repository descriptions
- Developer-style terminal with repository-grounded commands
- Resume and certificate links
- Direct GitHub and LinkedIn links
- Contact form that opens the visitor's email client
- No fabricated project metrics or GitHub popularity numbers

## Verified Technology Coverage

**Backend:** Node.js, Express.js, FastAPI, REST APIs, WebSockets

## Local Development

Clone the repository:

```bash
git clone https://github.com/shivamsharmakr04/Personal-Portfolio.git
cd Personal-Portfolio
```

Run a simple static server:

```bash
python -m http.server 8080
```

Then open the local address shown by the server.
