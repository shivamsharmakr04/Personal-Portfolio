# Shivam Kumar Portfolio

This project is a responsive personal portfolio website for Shivam Kumar, built with HTML, CSS, and JavaScript. It showcases the developer profile, technical skills, project work, work journey, GitHub activity, and contact information in a modern single-page layout.

## Overview

The site includes:

- Hero section with animated developer-style intro
- About and experience sections
- Skills and technology stack display
- Project showcase cards
- Mobile-friendly navigation
- Theme switcher with multiple color modes
- Particle background and motion effects
- Downloadable resume and certificate PDFs
- Contact links and email CTA

## How to Run

You can open the project directly in a browser, or run a local static server:

```bash
cd d:\Portfolio
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

- The project is a static front-end website and does not require a build step.
- Asset files such as resumes and certificates are stored in the root folder and reused by the portfolio sections.
- Project preview images are stored in `assets/images`.
