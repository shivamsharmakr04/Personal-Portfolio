## ✨ About the Project

This repository contains my personal developer portfolio, designed as a focused showcase of my work in **frontend and full-stack web development**.

The portfolio combines a clean developer-oriented interface with interactive visual elements to make projects, skills, experience, and contact information easy to explore.

Rather than relying on a heavy frontend framework, the project uses a lightweight **HTML + CSS + JavaScript architecture** with custom interactions and browser-native APIs.

---

## 🚀 Key Features

- 🎨 **Multi-theme visual system** for a personalized browsing experience
- ⚡ **Interactive particle background** powered by browser-side rendering
- 🧊 **3D card interactions** and visual hover effects
- 💻 **Developer-style terminal interface** for an interactive portfolio experience
- 🔎 **Project filtering and project detail views** for easier project discovery
- 📱 **Responsive layout** designed for desktop and mobile screens
- 🎞️ **CSS animations and micro-interactions** throughout the interface
- 📬 **Contact form integration** using Web3Forms
- 🧩 **Lightweight client-side architecture** without a frontend framework
- 🖼️ **Portfolio-focused presentation** for projects, skills, and professional information

## 🎯 Design & Engineering Focus

The portfolio was built around a few practical frontend principles:

- **Responsive design** — layouts adapt across screen sizes.
- **Interactive UI** — animations and interactions provide visual feedback without requiring a framework.
- **Component-like organization** — reusable UI patterns are kept manageable through structured HTML, CSS, and JavaScript.
- **Visual hierarchy** — projects, skills, experience, and contact information are separated into clear sections.
- **Performance-conscious architecture** — the project avoids the overhead of a large frontend framework for a primarily static portfolio.
- **Maintainability** — core behavior is implemented with standard web technologies that are easy to inspect and modify.

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/shivamsharmakr04/Personal-Portfolio.git
cd Personal-Portfolio
```

### 2. Start a local server

Using **serve**:

```bash
npx serve -l 8080
```

Or using Python:

```bash
python -m http.server 8080
```

Then open the local URL provided by the server.

## 🌐 Deployment

Because the portfolio is a client-side web application, it can be deployed to static hosting platforms such as GitHub Pages, Vercel, Netlify, or similar services.
